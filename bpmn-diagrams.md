## Ký hiệu BPMN sử dụng

| Ký hiệu | Tên | Ý nghĩa |
|---------|-----|---------|
| ( O ) | Start Event | Sự kiện bắt đầu |
| ( ● ) | End Event | Sự kiện kết thúc |
| [  ] | Task | Nhiệm vụ/Hoạt động |
| ◇ | Gateway | Cổng rẽ |
| → | Sequence Flow | Luồng tuần tự |
| ⟳ | Loop | Lặp |

### Mô tả luồng:
1. Học viên xem chi tiết khóa học và nhấn "Đăng ký ngay"
2. Hệ thống hiển thị form đăng ký
3. Học viên điền thông tin (họ tên, email, SĐT, ngày sinh, giới tính, địa chỉ)
4. Hệ thống kiểm tra validation:
   - **Pass**: Tạo đơn với trạng thái "Chờ xác nhận", thông báo thành công
   - **Fail**: Hiển thị lỗi validation, quay lại bước 3
5. Admin nhận thông báo về đơn đăng ký mới
